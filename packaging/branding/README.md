# Oznaczenia Telekomunikacji Kaliskiej

`tk-logo-original.png` to niezmieniona kopia pliku `tk_logo.png` dostarczonego przez użytkownika. `telekomunikacja-kaliska.png` usuwa wyłącznie przezroczyste zewnętrzne marginesy. Ikony `../tk-app.png`, `.ico` i `.svg` zawierają ten sam oryginalny znak, bez zmiany kolorów ani generowania nowego logo.

Logo, nazwa sieci i prawa do oznaczeń pozostają przy ich uprawnionym właścicielu. Licencja GPL kodu aplikacji nie jest zapewnieniem praw do znaku ani zgodą na jego niezależne wykorzystanie. Materiał dołączono zgodnie z poleceniem użytkownika do klienta SIP Telekomunikacji Kaliskiej.
